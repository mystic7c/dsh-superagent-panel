# 页面说明

面板挂在 DeepSeek Harness Web UI 的左侧栏（入口名「超级智能体」），六个页签对应 Superagent 的完整生命周期：
**消息进来源 → 触发评估 → 接单执行 → 闸门与验收 → 发布**。本页逐个说明每个页签能看到什么、能改什么。

## 概览

值班视图，回答"现在有什么需要我处理"。

- **待办箱**：闸门放行、待验收、干跑待发布、失败、来源异常、引擎异常，按优先级排序，可单条已读。
- **正在执行**：当前在跑的工单与阶段。
- **系统问题**：缺 token、没允许触发人、仓库异常等配置缺口，每条都带一个直达设置页的按钮。
- **过去 24 小时**：到达 → 过滤 → 接单 → 执行的漏斗，**运行质量**（成功率、平均耗时、自动修复次数、Top 失败原因）、
  策略规则命中与拦截统计、**系统脉搏**（引擎/执行器/轮询状态）。
- 首次使用时顶部显示四步配置清单（保存 Octo token → 添加监听群 → 绑定仓库 → 打开引擎）。

## 来源

Octo 消息从进来到变成工单的过程。

- 监听群列表、24 小时到达/过滤/接单计数。
- **原始信号台账**：每条消息的判定（接单 / 忽略 / 跳过 / 失败）与原因，可重放、可人工标注正确/误报/漏报，
  支持文本、状态、仓库、原因、时间范围筛选与分页。
- 健康检查与「检查新消息」按钮（只读试运行，不写入状态、不建工单）。

## 触发

评估视图：一条消息为什么被接单或被忽略。

- 线程列表与线程详情：消息时间线、评估过程、命中的规则、决定与理由。
- 支持按文本、仓库、原因、时间范围筛选与分页。

## 评估

决策台账（只读）。

- 接单 / 忽略两类决定的列表、命中规则与置信度。
- 按文本、仓库、原因、时间范围筛选与分页，**筛选状态写入 URL**，可直接分享当前视图。
- 模型改判与人工改判的**分歧视图**；shadow 模式下同时显示模型意见但不参与执行。

## 执行

执行器与工单队列。

- 执行器负载、暂停/恢复、工单队列台账（等人处理的排在最前）。
- 视图选项：按阶段或按仓库分组、多种排序、显示已结束；**「已忽略」切片**显示失败后被人放弃的工单。
- 手工建单：本地填标题与正文，直接进入执行队列。
- **工单详情**是面板最重的一页：
  - 改动内容（仓库、分支、验证方式、执行总结、改动文件与逐文件 diff）、需求正文；
  - 验收（轮次、逐项检查、人工 accept/reject，失败项带修复提示）；
  - 自动化（固定间隔 / 每天 HH:mm / 次数上限，显示下次运行与跳过原因）；
  - 阶段链路、各闸门结果、运行记录（trigger、停止原因、handoff、执行轨迹、报告、活动流）；
  - **追加要求**：输入后自动干跑重跑，保留当前工作树改动；
  - 干跑完成后主行动变为「发布 MR」；MR 卡显示草稿与过期 CI 提示；
  - 运行中可请求停止（真正取消 worker 与子进程后确认），中断的运行可继续，worker 提问可回答。

## 设置

除评估与提示词（只读参考）外均可写，保存前展示字段级差异，每次保存自动生成可回滚快照。

- **来源**：Octo token、启用引擎、允许任意人类/发送者名单、轮询间隔、监听群与仓库绑定。
- **运行**：执行器开关、自动执行、接单/派发暂停、MR 方式、执行超时、返工预算。
- **Worker**：多后端启用（DSH / Codex / Claude）、路由模式与任务类型偏好、模型与 CLI 路径、能力矩阵、独立验收后端。
- **写权限**：推分支、回群消息、合并 MR。
- **仓库**：GitLab token、新增/编辑/停用仓库（本地路径、GitLab 项目、分支、验证与验收方式）、只读测试配置。
- **变更历史**：查看与恢复 `live.json` 的历史快照。

更细的字段（worktree、UAT/健康检查地址、闸门 `repairHint`、删除仓库）仍在 `live.json` 中配置，
格式见设置页的「复制路径」与示例配置。
